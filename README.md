## Descripción  📙

Este curso intensivo ofrece una introducción práctica a tres herramientas fundamentales para la ciencia de datos y el desarrollo reproducible: Git para control de versiones, Bash para automatización en la terminal y R para análisis estadístico y visualización. No se requiere experiencia previa: comenzaremos desde cero y avanzaremos paso a paso, combinando teoría y práctica en un entorno accesible.

### Objetivos del curso 🔭

Brindar a los participantes una formación intensiva y práctica en Git, Bash y R, iniciando desde cero, para que puedan desarrollar flujos de trabajo reproducibles, automatizar tareas en la terminal y realizar análisis de datos con R. El curso busca que cualquier persona, sin necesidad de experiencia previa, adquiera las bases necesarias para aplicar estas herramientas en proyectos académicos, profesionales o personales.
